# 🎮 E-Sports Biometrics and Performance

Projeto desenvolvido para a disciplina de **Algoritmos e Estruturas de Dados I**, com o objetivo de trabalhar a manipulação de dados utilizando estruturas como **listas, dicionários e conjuntos**, além da geração de gráficos a partir de um dataset.

## 📚 Sobre o projeto

O projeto utiliza o dataset **E-Sports Biometrics and Performance**, disponibilizado pelo Kaggle, contendo dados relacionados a jogadores de e-sports, desempenho e indicadores biométricos.

O programa foi desenvolvido em **Python** e possui um menu interativo no terminal para realizar diferentes análises sobre os dados.

## 📊 Dataset

O dataset utilizado é:

**E-Sports Biometrics and Performance**

Arquivo principal:

```text
dados/esports_gaming_biometrics_250k.csv

O dataset possui aproximadamente 250 mil registros e informações relacionadas a:
- Identificação dos jogadores
- Idade
- Gênero do jogo
- Horas de jogo
- Horas de sono
- Consumo de bebidas energéticas
- Brilho da tela
- Uso de filtro de luz azul
- Ações por minuto (APM)
- Frequência cardíaca
- HRV
- Tempo de reação
- Resultado da partida


⚙️ Funcionalidades

O programa possui um menu interativo para realizar análises sobre os dados do dataset.
Entre as funcionalidades estão:


- Agrupamento e análise dos dados;
- Ordenação dos registros;
- Identificação dos melhores resultados;
- Comparação entre diferentes categorias;
- Análise utilizando conjuntos (set);
- Geração de gráficos.


🧩 Estruturas de dados utilizadas

Durante o desenvolvimento foram utilizadas estruturas fundamentais da linguagem Python:


- Listas (list)
- Dicionários (dict)
- Conjuntos (set)
Essas estruturas são utilizadas para armazenar, organizar, percorrer e analisar os dados do dataset.

📈 Gráficos

O projeto também possui funcionalidades para geração de gráficos utilizando os dados do dataset.
Os gráficos permitem visualizar relações e comparações entre diferentes informações presentes nos dados.
